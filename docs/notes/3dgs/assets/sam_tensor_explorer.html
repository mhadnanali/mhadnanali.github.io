What does 256 × 48 × 64 mean?

A hands-on tensor explorer. Move the channel slider, click a spatial cell, and see how one location contains a full 256-dimensional feature vector.

Controls
row = 24, col = 32
  • 256 = number of channels / feature dimensions.
  • 48 × 64 = spatial grid of the feature map.
  • F[c, :, :] = one channel map.
  • F[:, r, c] = one full 256-D vector at one spatial location.
