How does the model learn these vectors? — Feature loss and gradients

A toy interactive lab. The teacher target is fixed. Two Gaussians contribute to one pixel with weights w₁ and w₂. Watch the rendered feature, the loss, and the Gaussian feature vectors update.

This toy example uses a 4-dimensional feature vector so the updates are visible. The real model uses 256 dimensions.

Key idea
The target vector from the teacher is fixed. Only the Gaussian feature vectors change. The gradient tells each Gaussian how to change so the rendered feature becomes closer to the teacher target.
